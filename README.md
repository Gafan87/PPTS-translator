# PPTS Translator

Локальное веб-приложение для перевода текста в презентациях PPTX с сохранением структуры документа и форматирования. Поддерживает работу через DeepSeek API, несколько стилей перевода, ручное редактирование, визуальную разметку блоков, сохранение сессий и экспорт готовой презентации.

## Возможности

- перевод текстовых фигур, таблиц и текстовых данных диаграмм;
- несколько вариантов перевода с независимым выбором стиля для каждого блока;
- ручные правки без потери исходного ответа API и возможность восстановления;
- предпросмотр слайдов и наложение границ текстовых блоков;
- корректные абсолютные координаты обычных и вложенных групп с учётом масштабирования, поворотов и отражений;
- наследование геометрии placeholder из layout и master;
- разделение переводов между run через `|` и перестановка форматирования через `[2,1,3]`;
- пакетные запросы для больших презентаций и строгая проверка размеров ответа DeepSeek;
- сохранение и восстановление сессий, включая ручные правки, выбранные стили, метки и области;
- импорт JSON-ответа и mapping-файла через интерфейс без использования локальных путей браузера;
- экспорт переведённого PPTX.

## Требования

- Python 3.10 или новее;
- LibreOffice для преобразования PPTX в PDF при генерации превью;
- PyMuPDF устанавливается вместе с Python-зависимостями и преобразует PDF в PNG;
- ключ DeepSeek API только для автоматического перевода.

LibreOffice должен быть доступен в `PATH` как `libreoffice` или `soffice`. Без LibreOffice загрузка, редактирование, применение переводов и экспорт продолжают работать, но изображения слайдов не создаются.

## Установка

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

### Windows

```bat
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
```

При необходимости отредактируйте `.env`. Ключ API можно также указать в настройках приложения; не публикуйте `.env` и не добавляйте его в Git.

## Запуск

```bash
python app.py
```

По умолчанию приложение открывается по адресу <http://127.0.0.1:5001>.

## Рабочий процесс

1. Нажмите «Загрузить PPTX» и выберите презентацию.
2. Дождитесь генерации превью, если LibreOffice установлен.
3. Настройте язык, стили и фильтры, затем запустите перевод всех или выбранных слайдов.
4. Проверьте блоки на слайде. При необходимости меняйте их порядок, метки и области перевода.
5. Выберите стиль каждого блока и отредактируйте текст вручную там, где это нужно.
6. Нажмите «Применить перевод», чтобы записать изменения в рабочий PPTX.
7. Сохраните сессию или нажмите «Экспорт PPTX» для получения результата.

### Перевод нескольких run

Если блок содержит несколько независимо форматированных фрагментов, используйте `|` между их переводами:

```text
Первая часть | Вторая часть | Третья часть
```

Для перестановки форматирования добавьте порядок в начале строки:

```text
[2,1,3] Второй фрагмент | Первый фрагмент | Третий фрагмент
```

Переставляются только свойства `a:rPr`; XML-узлы самих run не перемещаются. Если разделитель отсутствует, перевод записывается в первый run, а остальные очищаются — текст не дублируется.

## Настройки окружения

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `APP_HOST` | `127.0.0.1` | Адрес Flask-сервера |
| `APP_PORT` | `5001` | Порт приложения |
| `FLASK_DEBUG` | `false` | Режим отладки; не включайте в общедоступном окружении |
| `DEEPSEEK_API_KEY` | пусто | Ключ DeepSeek API |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com/v1` | Базовый URL API |
| `DEEPSEEK_VERIFY_TLS` | `true` | Проверка TLS-сертификата |
| `PROMPT_BATCH_CHARS` | `24000` | Максимальный объём исходного текста в пакете |
| `MAX_UPLOAD_MB` | `200` | Максимальный размер multipart-загрузки |
| `CORS_ORIGINS` | локальные адреса порта 5001 | Разрешённые origins через запятую |

## Данные и сессии

Во время работы создаётся каталог `workspace/`:

- `upload/` — загруженные оригиналы;
- `work/` — распакованные рабочие PPTX и превью;
- `out/` — экспортированные презентации;
- `saved_sessions/` — сохранённые сессии;
- `settings.json` и TXT-файлы — пользовательские настройки, промпты, глоссарий и стили.

Активные сессии хранятся в памяти процесса и очищаются через 24 часа. Сохранённые сессии можно восстановить после перезапуска. Приложение рассчитано прежде всего на локальную работу; для многопользовательского развёртывания потребуется отдельная аутентификация, постоянное хранилище и управление фоновыми задачами.

## Поддержка PPTX и ограничения

- Геометрия рассчитывается композицией OOXML-преобразований `off`, `ext`, `chOff`, `chExt`, включая вложенные группы, повороты и отражения.
- Таблица обрабатывается как один блок, а её ячейки записываются по точным XML-путям.
- В диаграммах переводятся текстовые узлы и строковые кэши. Числовые `c:numCache` не изменяются.
- SmartArt, OLE-объекты и связанные внешние книги не редактируются как отдельные источники текста.
- Превью создаёт LibreOffice, поэтому его отрисовка может немного отличаться от Microsoft PowerPoint.
- Для проверки результата рекомендуется открыть экспортированный файл в PowerPoint или LibreOffice.

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты покрывают групповую геометрию, placeholders, таблицы, диаграммы, перестановку форматирования, варианты перевода, сессии, multipart-импорт, безопасность ZIP и состояния preview API.

## Структура проекта

- `app.py` — Flask API, сессии, DeepSeek, превью и экспорт;
- `pptx_geometry.py` — аффинные преобразования и абсолютные координаты;
- `pptx_text.py` — извлечение и запись текста PPTX;
- `index.html` — одностраничный интерфейс;
- `tests/` — регрессионные тесты.
